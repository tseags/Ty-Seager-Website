# Ty Seager Website

Personal portfolio and résumé site for [Ty Seager](https://www.linkedin.com/in/ty-seager/).

## Local preview

```bash
python3 -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080).

## Publish (GitHub Pages)

1. Push this repo to `tseags/Ty-Seager-Website` on `main`.
2. In GitHub → Settings → Pages → Source: Deploy from branch `main` / `/ (root)`.
3. Site URL: `https://tseags.github.io/Ty-Seager-Website/` (or your custom domain).

## Structure

- `index.html` — entry
- `css/` — Classical design system + page styles
- `js/site.js` — content + interactivity
- `assets/` — images
- `Ty-Seager-Resume.pdf` — downloadable résumé
